### Getting started

```bash
git clone https://github.com/Raimal-Raja/Online-Ride-Booking-app-Using-ReactJS.git
cd Online-Ride-Booking-app-Using-ReactJS
```

Use a Node.js version compatible with each application’s package manifest. Run the applications separately:

```bash
cd "my-react-app"
npm ci
npm run start
```

```bash
cd "my-app"
npm ci
npm run start
```

Browse the folders and linked notes above. This repository is a resource collection or documentation starter rather than a runnable application.
